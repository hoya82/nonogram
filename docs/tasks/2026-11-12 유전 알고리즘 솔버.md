# 유전 알고리즘 솔버

## 배경

마일스톤 [M1 — 유전 알고리즘 솔버](../milestones/M1%20유전%20알고리즘%20솔버.md) 를 만들고, 그 마일스톤으로 솔버 하나를 추가한다.
요구: ① 행과 열을 스캔 ② 경우의 수가 적은 축을 고른다 ③ 빈칸(건너뛰기) 삽입을 유전자로, 반대 축 불일치도를
평가 함수로 하는 GA ④ 불일치도 0 = 풀림 ⑤ 명백히 불가능하면 오류를 내고 끝낸다.
`docs/milestones/` 는 비어 있던 폴더라 이번 문서가 첫 마일스톤(M1)이다.

## 조사 / 원인 분석

### 설계에서 정한 것

- **경우의 수**는 "판에 이미 확정된 칸과 어긋나지 않는 배치 수" 로 센다(줄 DP). 빈 판이면 C(여유+조각 수, 조각 수) 와 같다.
  축 비교는 줄별 곱(로그 합). 그래서 사용자가 일부 칸을 칠했거나 다른 전략을 먼저 돌린 판에서도 이어 풀 수 있다.
- **유전자** `e[0..m]` = 틈마다 넣은 여분 빈칸 수(Σ = 여유). 디코드한 주 축 줄은 늘 단서를 만족한다.
  변이는 "빈칸 하나를 다른 틈으로 옮기기" = 사이 조각들을 한 칸씩 밀기.
- **불일치도**는 "맞는 반대 축 줄 개수" 처럼 거친 값 대신 줄마다 **최소 뒤집기 칸 수**(줄 거리 DP)의 합. 0 이면 모든 줄이 맞는다.
- **명백한 불가능**은 증명이 되는 것만: 단서 합 불일치, 배치 0 인 줄, 판 복사본에서 줄 전파 모순(줄 전파는 건전하다).
  GA 는 해가 없다는 걸 증명하지 못하므로, 그 밖의 불가능은 세대 한도에서 `stalled`. 전수 탐색으로 "줄 전파로 한 칸도
  못 정하고 모순도 없지만 해가 없는" 4×4 판(`rows [2],[2],[2],[1 1] / cols [2],[2],[2],[2]`)을 찾아 시험에 넣었다.
- 줄 전파 검사 결과는 불가능 판정에만 쓰고 GA 의 탐색 공간에는 넣지 않았다(요구대로 GA 가 푼다).

### 튜닝 중 알아낸 것

- **얼린 배열이 3배 느리다**: 퍼즐 단서는 `Object.freeze` 된 배열인데, bun(JSC)에서 줄 거리 DP 안쪽 반복이 2.4µs → 평범한 배열로 복사하니 0.7µs. 모델을 만들 때 복사한다.
- **교차**: 줄마다 부모를 고르는 균등 교차보다 이어진 줄 묶음을 바꾸는 두 점 교차가 커피잔에서 확실히 낫다(세로 구조가 덜 깨진다).
- **재시작**: 정체 시 최상위 개체를 남기고 다시 뿌리면 금세 같은 지역 최적(커피잔 불일치 6)으로 돌아간다 → 개체군을 통째로 새로 뿌리고 최선은 따로 기억.
  정체 판단도 "지금까지 최선" 이 아니라 "지금 개체군의 최선" 기준.
- **순수 GA 의 한계**: 15×15 까지는 확실히 풀지만 20×20 무작위 판은 5,000세대에도 불일치 8–14 에서 멈춘다(0/5).
  줄 전파로 83칸을 고정해 줘도 0/8(3,000세대, 불일치 2–6).
- **다듬기(메메틱)**: 세대마다 최선 개체에 변이를 수백 번 해 보고 불일치도가 나빠지지 않으면(같아도) 받아들이게 하니 20×20 10/10, 30×30 5/5.
  처음엔 매번 전체를 평가했는데, 바뀐 주 축 줄이 지나는 열만 다시 재는 증분 평가로 바꿔 같은 결과를 2배 빠르게 낸다.
  조합 몇 개를 병렬로 재서 `개체 100 · 다듬기 800` 을 기본으로 정했다. `polish: 0` 이면 순수 GA.

측정 전체는 마일스톤 문서의 "측정" 표.

## 남은 고려사항

- 진화 중에는 메모 칸도 "정한 칸" 으로 세므로 머리줄 진행률이 100% 로 보인다(가정 & 모순의 메모와 같은 기존 동작).
- 실행 도중 정지하면 후보 메모가 판에 남는다 — 메모 줄의 "지우기" 로 지운다(가정 & 모순과 같다). 세대 한도로 끝나면 전략이 지운다.
- 진화는 시작할 때의 판을 기준으로 한다. 일시정지 중 사람이 칸을 고치면 그 뒤 후보 그리기에서 그 칸은 건너뛰지만, 탐색 모델에는 반영하지 않는다.
- 기록의 줄 이름이 두 번 보인다(`C6 C6 [7]: …`) — 기존 전략들과 같은 형식(실행기가 줄 이름을, 메모가 다시 줄 이름을 붙인다).
- 해가 여럿인 판은 처음 찾은 해로 끝난다.
- 아무것도 커밋하지 않았다.
